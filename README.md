# Mini-Replit — Minecraft-Themed Browser IDE

A browser-based IDE inspired by Replit, skinned like Minecraft. Runs Python and
JavaScript/HTML entirely in the browser and ships with an AI-style AWS Cloud
Architect panel.

> 🚧 Under construction — being built in staged commits.

## Stack

- Vite + React 18 + TypeScript
- Monaco editor (`@monaco-editor/react`)
- Pyodide (WebAssembly Python, loaded from CDN)
- Custom Minecraft-themed CSS — no UI library

## Development

```bash
npm install
npm run dev
```
